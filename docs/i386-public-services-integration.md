# Public service integration, console interface 220

The main checkout now exposes the services required to advance the complete
original Find, God, Psalmody and FileMgr sources. The terminal audit of the
preceding nine-module native build verified all 1,272 pinned inputs before these
core changes were applied.

The raw renderer and public reversal pointer share their backing table; a second
public pointer exposes population counts. The existing word-character bitmap
is exported as its original U32 array, and the shared scan-code constants are
included by public key declarations. Existing signed ClampI64, PutFileLink and
MusicSettingsRst implementations gain their original public signatures.

PopUpPickDir, CopyTree and DelTree share exact original function bodies between
the original source files and native console. The recursive filesystem functions
are included before the original-media aliases, so their calls use normal
public dispatch. Console data-export bits distinguish the two table pointers
from function exports. Console interface 220 prevents older images from being
accepted as this interface.

The source-startup verifier now expects declarations completed before a syntax
error to survive, matching the original. Its missing-file fixture hides every
ancestor startup fallback in the full image; otherwise it was accidentally
loading the original root StartOS.HC. Runtime parent search is preserved.

Validation:

* Candidate v8 passes two original bootstrap generations and the cross-build's
  386 instruction audit (96 BIOS / 332 protected-mode instructions).
* All 15 applied source files exactly match candidate v8
  (`build/i386-public-tables-candidate-v8/main-applied-source-audit.json`).
* All 1,371 delivered source/document files match main
  (`build/i386-public-tables-main-source-audit-v1.json`).
* `build/i386-public-services-main-suite-v1/result.json` passes all eight
  component regressions: bit tables, word bitmap, signed clamp, serialized file
  links, original FileOcc, music reset, recursive copying and recursive deletion.
  Each checks independent expected values and fresh rendered arithmetic;
  filesystem-changing cases also verify preserved files and filesystem structure.
  All execution input pins remain unchanged.
* `build/i386-source-startup-main-v1/result.json` passes custom, syntax-error and
  missing-source cases at 8 MiB KVM 486,-fpu with exact pixel checkpoints and
  unchanged inputs.

The 16 MiB TCG diagnostic boot passes, including the exact 307,200-pixel
welcome raster (`build/i386-public-tables-main-minimal-v1/screen-oracle.json`).
Its 600-second observation allowance does not alter the interactive startup
budget or establish full minimal-profile qualification.
The full FileMgr loader now reaches missing Fmt; its picker workflow remains
unqualified. Psalmody reaches JukePuppet's type visibility and TaskCaller gaps.
The nine-module native result establishes compilation/persisted exports of its
preceding frozen image; installation, booting generated modules, two native
release generations, reproducibility and full C1–C5 qualification remain open.
